# websites

Static websites for the Roberts lab, served with GitHub Pages.

- `personal/`: Kirk Roberts's personal page. https://krobertslab.github.io/websites/personal/
- `bionlp2027/`: BioNLP 2027 workshop page. https://krobertslab.github.io/websites/bionlp2027/

Each site is plain HTML/CSS/JS with no build step. Edit the files and push to `main` to publish.
